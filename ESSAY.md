# KronoSim contest essay

I am Jann Carlo Martínez Cardona, a 24-year-old software engineering student at Universidad del Valle in Colombia. I am interested in distributed systems because they make it possible to understand how many small components cooperate under failure. I have experience programming with Kotlin, Java, Python, web technologies, databases, Android, and Compose Multiplatform. I enjoy exploring ideas through practical projects, especially applications that turn abstract concepts into something people can see and test.

My submission is KronoSim, an interactive laboratory for Raft consensus. I wanted to create a project that would let learners experiment directly rather than only read about elections, heartbeats, logs, and quorum. KronoSim supports clusters of three, five, or seven nodes. Users can crash or recover nodes, sever or restore network links, submit client writes, save topologies, and replay leader-failover and split-brain scenarios. Live telemetry shows elections, packet delivery, commits, and the transition of the network.

I began with the official Kotlin Multiplatform Contest starter kit, but KronoSim is a substantial project created specifically for this contest. The starter kit provided the project infrastructure; I designed and implemented the original consensus engine, topology model, partition analysis, simulator interface, persistence, and test scenarios. My implementation is shared in Kotlin with Compose Multiplatform, Room, Coroutines, and Koin. Most simulation behavior and UI state live in common code, allowing desktop and web to run the same engine and preparing Android and iOS for the same experience.

KronoSim combines my interests in distributed computing, Kotlin, and interactive education. Its purpose is to demonstrate that Kotlin Multiplatform can share much more than a visual screen: it can unify the logic, behavior, testing, and learning experience across platforms. I hope judges see an educational tool and an original example of how Kotlin Multiplatform unifies a complex domain model across platforms with a contest-specific purpose.
